# 🎬 Películas Web App

**¡Bienvenido a tu catálogo de películas y personajes!**  
Una aplicación full-stack con FastAPI (Python) en el backend y React + Bootstrap en el frontend. Permite:

- 📂 Gestionar películas (CRUD)  
- 🎭 Gestionar actores/personajes (CRUD)  
- 🔗 Relacionar múltiples protagonistas en cada película  
- 🔍 Filtrar películas por fechas (anteriores, hoy, próximas)  
- 🌐 Documentación automática con Swagger
